# Vikunja Agent MCP

Vikunja Agent MCP is an MCP server for agents that track work in Vikunja. The project is moving toward a short queue of actionable issues, stable ticket references, and triage guidance agents can open when they need it.

Source migration is in progress. [GitHub Issues](https://github.com/mikomiel/vikunja-agent-mcp/issues) tracks the initial tool port, issue workflow, skills, and installable release.

See [CONTRIBUTING.md](CONTRIBUTING.md) for review and checks and [SECURITY.md](SECURITY.md) for private reporting. The project is licensed under [Apache-2.0](LICENSE).
